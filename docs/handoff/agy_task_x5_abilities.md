# Task x5: Pocket Tanks pass, ability redesign of the existing weapons

Follow `docs/handoff/AGY_BRIEF.md` and `architecture/RECIPES.md`. Log entry first. Design source: `docs/monster_mash/09_expansion_design.md` section 3 (the table is the spec). The owner finds the current abilities too mediocre: each weapon needs one loud, readable, memorable signature with a clear payoff, in the spirit of Pocket Tanks (rollers, MIRV splits, clusters, drills, napalm pools, nukes, rains of projectiles). `regress:quick` is the loop, the full `regress` once at the end. Work in two batches and run `regress:quick` after each.

Batch A: Militia Blade (Whirlwind roll: rolls along the ground as a sawblade for 1.4 s carving wood and monsters), Iron Cleaver (Crater slam: visible crater, shock ring radius 60, crumbling falloff), Ashwood Staff (Ember volley: 3 homing bolts that split in two on hit), Scrapheap Scattergun (Cluster burst: pellets that pop into small blasts, every 3rd leaves a spark).
Batch B: Hunters Pike (Driller: bores through up to 3 blocks or monsters and leaves splinters that keep hurting for 1 s), Hunters Boomerang (Rebound: two passes, return at 2x, ricochets once off a block), Blast Tube (Nuke lob: big airburst, wide radius, long falloff, white flash, shock ring, heavy shake), Horned Scepter (Hellbrand: curse zone plus a 4 s fire pool that spreads along wood). Relic add-ons from the table: Skyforge Maul chain lightning (up to 5 targets while the field is up), Comet Fists rising stone spikes along the quake line (block shots for 3 s), Bulwark Disc shield ring per bounce and an explosion on the 6th.

Rules: every effect is deterministic (seeded `ctx.rng`), inside the particle cap (90, raise it only if you measure 60 fps on L12 and the boss level), numbers in data (`params`), one behaviour file per weapon, registry entries only, no `if (id === ...)`. New shared pieces: a timed fire-pool actor (damage tick, spreads on wood), a roller body that follows `ctx.groundAt`, a drill that ignores selected collisions, a crater/shock-ring effect. Update each weapon's card texts (launch/tap lines) and ability label. Keep balance: an ability adds at most 1.5x the weapon's nominal damage as extra effect damage, never one-shots a level, bands in `balance_bands.json` must still pass (re-tune data, not the bands, unless the design doc says so).

Art and sound: use the existing effect kit and WebAudio placeholders; add the sound ideas to `docs/monster_mash/10_sfx_plan.md` (what the later RUN `generate sfx` pass should make); do not call `rundot generate`.

Verify: headless assertions per ability (roll distance, crater radius, split counts, cluster pops, drill count, rebound pass count, fire-pool ticks, nuke radius falloff), screenshots of each effect at its peak step into `docs/handoff/shots/abilities/` (real captures, 2x crop), reviewed against `docs/monster_mash/08_design_direction.md`; redo any effect that is faint.

Done means: `npm run check`, `npm run build`, `npm run regress:quick` and the full `npm run regress` pass; `node tools/merkle.mjs seal`; append `DONE agy_task_x5_abilities` to `docs/handoff/agy_done.txt`. No commit or deploy.
