## Blockers (fix before `set-public`)

**B1 · Franchise name: "Omnitrix Dial".** "Omnitrix" is the Ben 10 trademark (Cartoon Network), and "a dial that drops five different alien arms" is the Ben 10 premise. The jam is "original ideas only", and the brief and catalogue rule is no franchise names. It is player-facing: weapon name, shop, `w_omnitrix_dial`, `sfx.omnitrix`, `art/omnitrixTextures.ts`, level 19 reward, design doc.
- **Fix:** rename it to something original, for example **"Fivefold Gauntlet"** or **"Skyfall Dial"**, with id `w_fivefold_gauntlet`. Recolour the dial away from green and black. Keep the mechanic (five falling arms is fine once it isn't Ben 10's). The game isn't public, so renaming the id is safe now; after launch it isn't. Needs owner approval (it renames content).
- **Also check:** "Pocket Tanks" and "Angry Birds" appear only in internal docs and the reference image (B4), not in the game. Keep it that way. Brahmastra is mythology, which is fine.

**B2 · Boss fights aren't reproducible (projectile re-hit damage).** `battle/damage.ts` `projectileHit()` ignores `t.cool`. A projectile resting on a monster damages it on every contact event (the log measured 1300 HP in 110 steps from one Cleaver). The local log says bosses are balanced around it. On this machine the quick regression gave:

```
FAIL Level 12: shots 2 outside allowed band [3, 5]
FAIL Level 20: shots 6 outside allowed band [3, 5]
FAIL Level 24: shots 2 outside allowed band [3, 5]
✓ Levels 1, 4, 8, 16 in band
```

The same code passed on the local machine. So boss outcomes depend on the machine or frame timing, and the most likely source is the jittering resting contact. For players this means a boss sometimes melts and sometimes doesn't. It also makes the daily leaderboard unfair.
- **Fix (one card, before the 29 Oct freeze):**
  1. Gate projectile hits per (projectile, target) pair with a cooldown (reuse `hitCooldownSteps` or add `projRehitSteps`).
  2. Ignore hits below `projMinSpeed` even when `info.status` is set, unless it's the first contact.
  3. Then lower boss HP and armour with `tools/tune_boss.mjs` and the solver until bands 12/16/20/24 pass on two machines (local plus cloud).
- If the owner prefers to keep the current feel, at least make the contact damage deterministic (a damage-per-second cap while resting), and widen the boss bands on purpose.

## Should fix

**B3 · `tools/regress.mjs` kills every Chrome on the owner's PC.** Cleanup runs `taskkill /F /IM chrome.exe`, which closes the owner's own browser windows on every run.
- Kill only the spawned PID (`taskkill /F /T /PID <pid>` is already there).
- On Linux/macOS use `process.kill(pid)`. Cleanup is currently Windows-only, so Vite and Chrome leak.
- Add `--no-sandbox` when `process.getuid?.() === 0` (needed in the cloud container).
- Section 3c took over 15 minutes here and hit my 20-minute timeout. Add a per-section timeout so it fails instead of hanging.

**B4 · Repo hygiene.**
- **Committed logs:** `vite4.log`, `vite5.log`, `vite6.log`, `gen_log.txt` and `docs/handoff/agy_chain.log`. `git rm` them and add `*.log` and `gen_log.txt` to the root `.gitignore`.
- **`MERKLE.json` (4 085 lines):** it changed in 32 of the 55 commits. Generated files in git cause merge conflicts between agents. Generate it on demand (`npm run merkle:seal`) and git-ignore it, or keep only the root hash in `MERKLE.md`.
- **Screenshots:** `docs/handoff/shots/` is 209 PNGs and 18 MB, which is most of the repo's growth. Keep only the latest set per check (overwrite) or store them outside git.
- **`docs/handoff/ref_angry_birds_layout.png`:** a screenshot of a commercial game in the repo. Delete it, and describe the layout in words if it's still needed.

**B5 · Orientation on RUN.** The game is now landscape (`game.config*.json` says `landscape`). The log asks whether the RUN host honours that for a game first registered portrait. This needs a phone check on the deployed build before going public. If the host stays portrait, the rotate overlay will show for everyone.

**B6 · Leaderboard submits a fake duration.** `platform/rundot.ts` sends `duration: 60` on every score. If RUN uses duration for anti-cheat or tie-breaks, real play time (steps / 60) is better. Check the leaderboard doc in `node_modules/@series-inc/rundot-game-sdk/docs`.
