## Tooling and gotchas
- **Dev server:** `npx vite --port 5212 --strictPort`, start it detached (PowerShell `Start-Process`); the browser pane is hidden so use headless Chrome through `tools/probe.mjs "<js>"` (set `SHOT=path.png` for a screenshot). Pass `http://localhost:5212/?mock=1` as the second argument for the mock platform.
- **Test hook** `window.__mm` (`load`, `fire`, `run`, `settle`, `sweep`, `solveStep`, `play`, `state`, `give`, `profile`, `battle`). **A level's own `loadout` field overrides the loadout you pass.**
- `bash tools/solve_levels.sh 12 16` prints solver shots and boss HP left (fast way to tune a level). `regress:quick` runs levels 1, 4, 8, 12, 16, 20, 24 (use `LEVELS=...` to choose). Do not run probes in parallel with a regress (it caused one transient failure).
