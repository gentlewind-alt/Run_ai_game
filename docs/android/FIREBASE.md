# Firebase for Monster Smash: Siege Slingshot (Android)

Online play is asynchronous: score boards, shared levels (Global Challenges) and challenge codes. No live matches.
The app signs players in anonymously, so there is no account, email or password and nothing personal is stored.

## One-time setup (done by the owner in the Firebase console)

1. Create the project and add the Android app `com.godspeedsamarth.monstermash`; put `google-services.json` in
   `game/android/app/` (it is git-ignored).
2. Build > Authentication > Sign-in method > **Anonymous** > Enable.
3. Build > Firestore Database > Create database > Standard > production mode (location cannot be changed later).
4. **Security rules:** Firestore Database > **Rules** tab > replace everything with the contents of
   `docs/android/firestore.rules` > **Publish**. Repeat after any change to that file.

No indexes are needed: every query is one field order or one equality filter.

## What lives where

| Path | What | Who may write |
|---|---|---|
| `boards/<board>/entries/<uid>` | a player's best score on a board (`level_N`, `overall`, `daily_<date>`): name, score, updatedAt | that player, only a higher score, score 1 to 1,000,000 |
| `ugc/<type>/items/<id>` | a shared level (`mm_challenge`) or a challenge score (`mm_s_<id>`): author, generated name, title, JSON payload, uses, reports | the author edits or deletes; anyone adds 1 to `uses`; anyone who reported adds 1 to `reports` |
| `ugc/<type>/items/<id>/reports/<uid>` | one report note per player | that player, once |

Names are generated by the app ("Brave Otter 482", lists in `config.json` `social.names`) and the rules accept only that shape.
A shared level's title (1 to 40 characters) is the only free text players can see from others, so every shared level has a
**Report** button; at `social.hideAfterReports` (5) reports a level disappears from browsing. To remove one for good, open it in
the console (Firestore > Data > `ugc` > `mm_challenge` > `items`) and delete the document.

## Limits to know

- **Scores are checked for range, not replayed.** A determined cheater can post any score up to the limit. Fixing that needs a
  server function that replays the shots (Blaze plan); the game is deterministic, so it is possible later.
- **Reads cost money past the free allowance** (50,000 per day on the free plan). Finding a player's rank reads the top
  `social.rankScan` (50) rows of a board; lower the number in `config.json` if the bill grows. Set a budget alert in Google Cloud.
- Everything falls back silently when the phone is offline: boards are empty and the Challenges screen shows nothing new.
